# AgentPaw application icon

The product icon is separate from the bundled character artwork. Its source is `icon-source.png`; `node scripts/build-brand-icons.js` generates the PNG, tray PNG, and Windows ICO in the parent directory.

Generated with the built-in imagegen tool on 2026-09-24. Independent generation is not a trademark clearance or a guarantee of exclusive rights.

Final prompt:

> Create an original distinctive Windows application icon for AgentPaw, a universal AI desktop companion and task monitor. No animal paw, pads, toes, animal silhouette, or blue. A single asymmetrical mint-green folded ribbon forms an open doorway/desktop window, with a detached small coral-orange square near the upper-right opening. Rounded geometry, broad strokes, simple silhouette, deep charcoal rounded-square tile and transparent exterior. No letters, terminal prompt, robot face, magnifying glass, or existing company emblems. Large centered symbol with padding for 16px and 32px use. Convey a companion entering the workspace, independent from any character IP.
