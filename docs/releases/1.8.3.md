# Codex 喵伴（WorkMeow）1.8.3

这一版修复 Codex 历史累计在台账升级或重算后缩水的问题，并改善设置和详情面板的文字可读性与布局。仓库更名为 **[codex-desktop-pet](https://github.com/vista-zhangg/codex-desktop-pet)**，产品仍叫 Codex 喵伴（WorkMeow）。

## 累计历史保护与恢复

- “累计统计”显示当前 Windows 用户在本机已记录的各工具历史，不随今日、7 天、30 天筛选变化；不是整台电脑所有账户、云端设备或未记录调用的总和。
- Codex 台账升级保留原累计，并在迁移前备份。活动会话和归档会话均纳入扫描，归档移动、重复读取、重启和重建日明细不会重复累加；源日志消失后保留已记录的累计。
- 已记账的 Codex 累计费用保留原估算，新调用按当前价格累加，避免价格刷新重新定价整段历史。费用是 API 等价估算，不是订阅账单或实际付款金额。
- 提供从明确选定的历史台账恢复累计的离线命令：以历史快照为基数，仅追加快照时间之后的去重记录；重复恢复不会叠加，降低现有累计的备份会被拒绝。此前已经丢失的历史需要仍存在的备份或源日志，升级不会凭空补出缺失数据。操作见[历史用量保护与恢复](https://github.com/vista-zhangg/codex-desktop-pet/blob/v1.8.3/docs/LOCAL_DEPLOYMENT.md#历史用量保护与恢复)。

## 设置与详情面板

- 可见文字最小字号调整为 12px，说明与标签按用途使用更清晰的字号，保留重点数字和标题的突出层级。
- 收紧设置内容宽度、卡片留白和过宽的输入区域；根据功能分组调整按钮、开关与说明之间的距离，让常用操作更集中。
- 改善小窗口中的表情管理、设置导航、详情统计与趋势图标签，减少拥挤和不必要的空白。
- 累计统计新增范围与费用说明，明确它与时间筛选的区别。

## 仓库与升级兼容

仓库、About 介绍、项目主题和中英文下载入口围绕 Codex 桌宠、桌面陪伴、AI 任务与用量监控更新。应用内更新和反馈链接同步指向新仓库，原仓库地址继续通过 GitHub 重定向服务旧客户端。

应用 ID、`WorkMeow.exe`、安装包命名与 `~/.workmeow/` 数据目录保持不变。当前仍支持 Codex、Claude Code、TRAE、WorkBuddy、opencode 和 ZCode。

## 安装与更新

已有安装版可通过应用内更新升级，也可下载 **`WorkMeow-1.8.3-Windows-x64.exe`** 覆盖安装。Release 仅上传 EXE 安装包与自动更新所需的 `latest.yml`，用户无需手动下载后者。

当前仅支持 **Windows x64**；界面为简体中文。安装包尚未进行商业代码签名，首次运行可能出现 SmartScreen 提示。迁移后的 v5 Codex 台账应继续使用 1.8.3 或后续兼容版本，旧版无法理解新格式。
