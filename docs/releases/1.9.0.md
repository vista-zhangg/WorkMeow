# AgentPaw · AI 桌伴 1.9.0

面向 Codex、Claude Code、TRAE、WorkBuddy、opencode 和 ZCode 的 Windows AI 桌宠与编程桌伴。任务提醒、Codex 订阅额度监控、token 用量统计和休息提醒，现在可以由你选择的角色来陪伴。

## 三套内置角色，也能创建自己的伙伴

- 内置 **打工猫、奶茶鼠、小蜜蜂蜜蜜**，复用同一套工作、反馈与休息状态。
- 设置中前三张卡片为内置角色，第四张是 **“＋ 自定义角色”**。输入名称并选择一张待命 GIF 即可创建角色，也可导入 `character.json` 整套动作。
- 每个角色独立保存 GIF。单个状态支持新增轮换、替换、移出和恢复默认，角色间的调整互不影响。
- 奶茶鼠保留原背景，小蜜蜂蜜蜜保留原生透明背景。没有专用动作的状态注明临时分配，后续可自行替换。

## 新品牌与升级兼容

- 产品名称统一为 **AgentPaw · AI 桌伴**，更新应用、任务栏和托盘图标。
- 新程序为 `AgentPaw.exe`，数据目录为 `~/.agentpaw/`。首次启动复制旧版配置、角色和历史记录，保留原目录作为恢复备份。
- 延续已有安装标识和更新通道，兼容旧版 Hook、环境变量与角色包格式，升级后继续使用原有数据。

## 下载与安装

下载 **`AgentPaw-1.9.0-Windows-x64.exe`**。已有安装版可使用应用内更新，或退出旧版后覆盖安装。附件 `latest.yml` 供自动更新使用，无需手动下载。

当前仅支持 **Windows x64**，界面为简体中文。安装包未进行商业代码签名，首次运行可能出现 SmartScreen 提示。本版继续保留任务提醒、5h / 7d Codex 额度、用量面板、全屏免打扰与喝水/伸展/远眺提醒。
