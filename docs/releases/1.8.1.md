# 打工喵 WorkMeow 1.8.1

恢复熟悉的桌面胶囊，保留 1.8.0 的详情面板与设置页面优化。

## 桌面胶囊

- 完整还原 1.7.14 的胶囊外形、尺寸、间距、字体、字号与字重。
- 恢复暖棕底色、米白文字、订阅额度配色，以及等待、异常等状态的提示样式。
- 设置页中的胶囊预览同步使用相同样式；隐藏猫咪时的状态点布局也与原版一致。

## 开发维护

新增独立的 UI 预览命令，将预览日志写入文件，并在异常或超时时自动退出，修复本地预览脚本因输出管道关闭而触发的 `EPIPE` 弹窗。

## 安装与更新

支持 Windows x64。已有 1.7.x 或 1.8.0 安装版可通过应用内更新升级，也可下载 `WorkMeow-1.8.1-Windows-x64.exe` 覆盖安装。

Release 仅上传 EXE 安装包与自动更新必需的 `latest.yml`。无需自行下载 `latest.yml`；GitHub 自动提供的 Source code 文件面向开发者。
