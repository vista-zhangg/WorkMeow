# 打工喵 WorkMeow 1.8.0

这一版集中打磨详情面板、设置页面与桌面胶囊，让信息更清晰，操作更轻盈。

## 界面焕新

- **详情面板**：全新的浅色界面、用量数字层次与趋势图；优化统计分组、窄窗口排版和时间范围切换。
- **设置页面**：新增通用、桌面胶囊、Agent 接入、版本更新、喵咪表情五类侧栏导航；统一控件、留白和键盘操作。
- **桌面胶囊**：采用石墨灰材质，重新整理订阅额度与用量展示；设置中可以即时预览展示组合。
- **自然动效**：页面、图表和任务状态平滑切换，支持系统“减少动态效果”；日常数据刷新不会重复播放切换动画。
- **稳定性**：修复桌宠共享脚本在浏览器环境中的加载错误。

## 安装与更新

支持 Windows x64。下载安装 `WorkMeow-1.8.0-Windows-x64.exe`，可覆盖升级已有安装版。

已有 1.7.x 安装版也可以通过应用内更新升级。Release 仅保留 EXE 安装包与自动更新必需的 `latest.yml`；更新使用完整安装包，并校验 SHA-512。无需自行下载 `latest.yml`。

本版本不提供 ZIP 便携包；GitHub 自动生成的 Source code 文件面向开发者。
