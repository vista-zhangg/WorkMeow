# Codex 喵伴（WorkMeow）1.8.2

打工喵更名为 **Codex 喵伴（WorkMeow）**：面向 Codex 的 Windows 桌宠与 AI 编程陪伴助手，继续支持 Claude Code、TRAE、WorkBuddy、opencode 和 ZCode。这一版新增按电脑使用时间运行的休息提醒，以及全屏免打扰和临时安静，喵形象与胶囊模式均可使用。

## 陪伴与休息

- 新增喝水、起身伸展与护眼远眺提醒。按你使用电脑的时间累计，无论 AI 是否在运行、任务是否结束都能提醒。
- 设置新增「陪伴与休息」页面，可关闭全部提醒，也可分别调整每一类的开关和间隔（5–240 分钟）。默认开启喝水（45 分钟）和伸展（60 分钟）；远眺默认关闭，开启后默认间隔为 20 分钟。
- 喵形象和仅胶囊模式均显示休息卡片，支持「完成」「稍后提醒」和「今天跳过」。稍后提醒默认为 10 分钟，可调整为 1–240 分钟；推迟期间全部休息提醒都会等待。「今天跳过」暂停当天全部休息提醒，重启后仍生效。
- 离开电脑至少 5 分钟后暂停累计，并重新开始伸展和远眺计时；喝水的累计时间保留。锁屏和休眠期间不累计，回来时不会补算离开时间。
- 多项到期提醒合并展示。正在处理授权卡或其他弹层时，胶囊保留轻提示，点击即可稍后提醒；完整休息卡片会等弹层关闭后再展开。

## 全屏免打扰与临时安静

- 默认开启「全屏时自动藏起」，可在设置中关闭。前台应用进入全屏时同时隐藏喵和胶囊，退出全屏后恢复原来的显示模式，后台任务监控与用量记录继续运行。
- 右键喵或胶囊的「收起」、托盘中的「临时安静与全屏免打扰」均提供安静 15 / 30 / 60 分钟，以及设置中保存的自定义时长（1–1440 分钟）。
- 临时安静到期后自动恢复；若仍在全屏，则等退出全屏后再出现。手动「藏起」不会被退出全屏或计时到期自动唤出。
- 托盘「显示 Codex 喵伴」可提前结束临时安静，并在当前全屏期间主动显示。窗口隐藏期间不弹出休息提醒。

## 名称与兼容性

应用标题、托盘、设置、安装程序和项目介绍统一采用新名称，突出 Codex 桌宠、桌面陪伴、订阅额度监控与 token 用量统计定位。本项目仍是独立开源项目，与 OpenAI 无隶属关系。

应用身份、`WorkMeow.exe`、安装包命名、仓库地址与 `~/.workmeow/` 数据目录保持不变，升级沿用现有配置和用量历史。

## 安装与更新

已有 1.7.x、1.8.0 或 1.8.1 安装版可通过应用内更新升级，也可下载 **`WorkMeow-1.8.2-Windows-x64.exe`** 覆盖安装。

Release 仅上传 EXE 安装包与自动更新必需的 `latest.yml`，用户无需自行下载后者。GitHub 自动提供的 Source code 文件面向开发者，不是应用安装包。

当前仅支持 **Windows x64**，不支持 macOS、Linux 或 Windows on ARM。应用界面为简体中文；安装包尚未进行商业代码签名，首次运行时可能出现 SmartScreen 提示。
