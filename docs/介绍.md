# 打工喵（WorkMeow）使用介绍

打工喵是一只桌面上的实时工作提示喵。它把 Claude Code、Codex、TRAE、WorkBuddy、opencode 的工作状态集中到同一个小窗口里：忙时动起来，等待你决定时举手，完成或出错时给出明显反馈。

## 你能看到什么

- 喵的动画表示当前聚合状态：工作、思考、等待授权、等待回复、清理、完成、出错、摸鱼或睡眠。
- 喵头顶的气泡和工具小图标表示最近的消息或动作。
- 喵旁边的行动入口收集需要你处理的权限卡和问题卡。
- 右键喵可以打开三个固定动作：详情、收起、隐私；隐私按钮上方以 ON/OFF 显示当前状态。
- 左键按住喵即可拖动；松开后会自动贴合屏幕边缘，避免下次启动漂移。
- 任务栏托盘菜单保持精简，只提供详情、显示/隐藏、设置和退出；隐私开关及 Agent 接入检查、修复、卸载集中在对应入口中。

## 接入范围

| 工具 | 监控方式 | 是否修改工具配置 |
| --- | --- | --- |
| Claude Code | 生命周期 hook、transcript 和本地进程 | 仅安装/卸载本项目 hook；权限决定由你在喵上完成 |
| Codex | 读取本机 rollout JSONL | 不修改 |
| TRAE | 读取 IDE 日志和本地进程 | 不修改 |
| WorkBuddy | hook、转录和用量字段 | 仅安装/卸载本项目 hook |
| opencode | 插件机制（事件推送 + 用量行追加） | 仅安装/卸载本项目插件文件 |

界面对外统一显示为一只“打工喵”，工具来源仍会在会话行和统计来源中标注。某些 Windows 安装路径仍使用 `ChatGPT.exe`，这是程序文件名，不是界面名称或统计分类。

## 详情面板与价格

点击喵的详情入口，可以查看五个工具合并后的 token、缓存读写、模型、上下文窗口、成本和趋势。价格优先使用 [models.dev](https://models.dev) 同步的公开 API 价目表，其次使用本地缓存、用户覆盖价和内置回退价。Windows 版通过 Electron 网络层继承系统代理和 PAC 设置；启动后会同步一次，成功后每 24 小时刷新，失败时按 1、5、15、60 分钟逐级重试。

面板显示的是“API 公价折算”，不是订阅账单。价格会标出当前来源、更新时间和同步状态；同步失败时继续使用最后一份有效缓存并显示下次重试时间。Claude、Codex、TRAE、opencode 会按各自策略使用精确价或回退价，WorkBuddy 未匹配到精确价格时不虚构费用（显示为 $0）。用户可以修改价格文件后运行 `npm run meter:rebuild`，一次重算五个来源的历史台账。

## 安装

```powershell
npm ci
npm start
```

首次启动会将本项目 hook 合并到对应配置文件，不会覆盖已有配置；卸载时会先备份。只想检查界面，可以在 PowerShell 中执行：

```powershell
$env:WORKMEOW_NO_HOOKS='1'
npm start
```

Codex 通过读取 rollout 文件工作，不需要额外注册 hook。开发和测试时可以用 `WORKMEOW_CODEX_DIR`、`WORKMEOW_TRAE_DIR`、`WORKMEOW_WORKBUDDY_DIR` 指向隔离目录。

设置中的“接入健康检查”只核对已经检测到的工具；“一键修复”不会为未安装的 Agent 创建配置目录。Claude Code、WorkBuddy 与 opencode 会对账各自的 Hook/插件，Codex 与 TRAE 分别检查 rollout 和日志只读监听器。最近事件时间只来自内存中的会话元数据，不读取或展示提示词、回复正文、项目完整路径或运行时令牌。

设置窗口中的开机启动和隐私开关会立即生效；下班彩蛋时间保存到本机配置，只在打工喵空闲或休息时播放，任务进行中会自动让位。Agent 接入区域可卸载 WorkMeow 管理的 Hook 和插件，不会卸载 Agent 本体，之后仍可一键修复。

隐私模式开启后，项目名、消息正文、授权命令、方案/问题选项和操作流明细会立即遮蔽，但工作状态和用量仍保留。关闭隐私模式后，未处理的授权或回复会重新出现。

## 常用命令

```powershell
npm run start:console
npm test
npm run install:hooks
npm run uninstall:hooks
npm run meter:rebuild
```

`npm test` 当前包含 36 套回归，覆盖本地 server、权限生命周期、状态聚合、隐私遮蔽、价格解析与同步、五个 Agent 接入、设置配置、拖动坐标和边缘菜单几何。网络价格同步失败不会让测试连接被异常重置；程序会保留有效缓存、反馈失败状态并自动重试。

## 数据边界

所有会话和统计数据保存在本机的 `~/.workmeow/`。价格同步只下载公开价目表，不上传 transcript、rollout 或权限内容。服务只监听本机回环地址，写请求需要运行时令牌。

更完整的文件结构和维护约定见根目录的 [README](../README.md) 和 [状态规范](../STATES.md)。
