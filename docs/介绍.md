# Codex 喵伴（WorkMeow）使用介绍

Codex 喵伴（WorkMeow）是面向 Codex 的 Windows 桌宠与 AI 编程陪伴助手，也支持 Claude Code、TRAE、WorkBuddy、opencode 和 ZCode。它把任务状态、订阅额度和用量集中到同一个小窗口里：忙时动起来，需要你时举手，也提醒你喝水、伸懒腰。这是社区开发的独立开源项目，与 OpenAI 无隶属关系。

## 你能看到什么

- 喵的动画表示当前聚合状态：工作、思考、等待授权、等待回复、清理、完成、出错、摸鱼或睡眠。
- 喵头顶的气泡和工具小图标表示最近的消息或动作。
- 喵旁边的行动入口收集需要你处理的权限卡和问题卡。
- 右键喵或胶囊可打开详情、收起和隐私；「收起」中可以手动藏起，或选择安静 15 / 30 / 60 分钟；隐私按钮上方以 ON/OFF 显示当前状态。
- 左键按住喵即可拖动；松开后会自动贴合屏幕边缘，避免下次启动漂移。
- 任务栏托盘保留月薪喵头像，右键菜单显示 Codex 5h / 7d 剩余百分比、刷新点和更新时间；没有服务端数据的窗口显示 `--`。

## 陪你休息，也懂得安静

在设置的「陪伴与休息」中调整喝水、伸展与远眺提醒。默认开启喝水（每 45 分钟）和伸展（每 60 分钟），远眺提醒（每 20 分钟）可按需要开启。总开关、每一类提醒的开关和间隔，以及「稍后提醒」的时长都可自行调整。

提醒累计的是你使用电脑的时间，与 Codex 或其他 AI 是否运行、是否结束任务无关。喵形象和胶囊模式都会显示提醒，可以选择完成、稍后提醒或今天跳过。每类提醒间隔可设为 5–240 分钟；稍后提醒默认为 10 分钟，可设为 1–240 分钟，推迟期间不会插入另一类提醒。今天跳过会暂停当天全部休息提醒，重启后仍生效；关闭后重新开启总开关可提前恢复。连续离开电脑至少 5 分钟后，伸展和远眺的连续使用计时重新开始，喝水的累计时间保留；休眠或锁屏期间不累计，也不会在回来时补发一串提醒。

授权卡或其他弹层正在显示时，胶囊上会保留“喝口水”等轻提示，点击即可稍后提醒，不关闭正在填写的内容。弹层关闭后再展开完整休息卡片；隐藏窗口期间不会抢先弹出。

全屏免打扰默认开启，可在设置中关闭。电脑进入全屏应用时，喵和胶囊都会通过现有隐藏方式藏起；退出全屏后恢复原来的显示模式。任务监控和用量记录继续在后台运行。

右键喵或胶囊的「收起」，或托盘中的「临时安静与全屏免打扰」，可选择安静 15 / 30 / 60 分钟，也可使用设置中保存的自定义时长（1–1440 分钟，默认 30 分钟），到时再显示。手动「藏起」会一直保持隐藏，不会被全屏退出或计时到期重新唤出。托盘「显示 Codex 喵伴」会取消临时安静，并允许你在当前全屏应用内主动显示；这一例外在本次全屏结束后解除。隐藏期间不弹出休息提醒。

## 接入范围

| 工具 | 监控方式 | 是否修改工具配置 |
| --- | --- | --- |
| Codex | 读取本机 rollout JSONL；监听官方 App Server 订阅额度 | 不修改，也不读取凭据文件 |
| Claude Code | 生命周期 hook、transcript 和本地进程 | 仅安装/卸载本项目 hook；权限决定由你在喵上完成 |
| TRAE | 读取 IDE 日志和本地进程 | 不修改 |
| WorkBuddy | hook、转录和用量字段 | 仅安装/卸载本项目 hook |
| opencode | 插件机制（事件推送 + 用量行追加） | 仅安装/卸载本项目插件文件 |
| ZCode | 生命周期 hook（事件名在 stdin 载荷中）+ 只读轮询 ZCode 的 `model_usage` SQLite 台账 | 仅合并安装/卸载 `~/.zcode/cli/config.json` 的 hook 块 |

界面对外统一显示为一只“Codex 喵伴”，工具来源仍会在会话行和统计来源中标注。某些 Windows 安装路径仍使用 `ChatGPT.exe`，这是程序文件名，不是界面名称或统计分类。

## 详情面板与价格

点击胶囊上的 5h / 7d 额度区域打开详情卡即可查看刷新倒计时和具体时间，鼠标移开后自动收起，不再使用会遮挡视野的原生悬停提示。点击喵的详情入口，可以查看六个工具合并后的 token、缓存读写、模型、上下文窗口、成本和趋势。价格优先使用 [models.dev](https://models.dev) 同步的公开 API 价目表，其次使用本地缓存、用户覆盖价和内置回退价。Windows 版通过 Electron 网络层继承系统代理和 PAC 设置；启动后会同步一次，成功后每 24 小时刷新，失败时按 1、5、15、60 分钟逐级重试。

面板显示的是“API 公价折算”，不是订阅账单。价格会标出当前来源、更新时间和同步状态；同步失败时继续使用最后一份有效缓存并显示下次重试时间。Claude、Codex、TRAE、opencode 会按各自策略使用精确价或回退价，WorkBuddy 未匹配到精确价格时不虚构费用（显示为 $0）。用户可以修改价格文件后运行 `npm run meter:rebuild`，一次重算六个来源的历史台账。

Codex 订阅额度与 token 台账完全独立。WorkMeow 启动时会自动发现桌面 Codex 自带的 CLI，保持一个 `codex app-server --stdio` 进程；完成 `initialize` 后先用 `account/read` 确认当前账户，再调用 `account/rateLimits/read`，并合并 `account/rateLimits/updated` 增量通知。解析时优先采用 `rateLimitsByLimitId.codex`，只有缺失该 bucket 才回退到兼容字段 `rateLimits`。5h 或 7d 任一窗口没有返回时不会按订阅计划猜测；正常为中性色，剩余不高于 20% 变为 amber，不高于 5% 变为 red，全部不可用则是灰色 `--`。临界气泡按 `(windowId, resetsAt)` 去重；桌宠隐藏或用户正在操作弹层时先排队，真正显示后才认领本周期，因此既不抢当前界面，也不会永久吞掉提醒。

## 安装

```powershell
npm ci
npm start
```

首次启动会将本项目 hook 合并到对应配置文件，不会覆盖已有配置；卸载时会先备份。只想检查界面，可以在 PowerShell 中执行：

```powershell
$env:WORKMEOW_NO_HOOKS='1'
npm start
```

Codex 状态通过读取 rollout 文件工作，不需要额外注册 hook；订阅额度由 Codex App Server 自己完成认证。WorkMeow 只把 `auth.json` 目录项替换作为 file auth 的快速重连信号，不打开或解析该文件；keyring / auto / ephemeral 的账户变化没有文件 watcher 保证，依靠 App Server 通知、周期性 `account/read` 与定期重建连接收敛。WorkMeow 不抓取 ChatGPT 网页接口。开发和测试时可以用 `WORKMEOW_CODEX_DIR`、`WORKMEOW_TRAE_DIR`、`WORKMEOW_WORKBUDDY_DIR` 指向隔离目录。

设置中的“接入健康检查”只核对已经检测到的工具；“一键修复”不会为未安装的 Agent 创建配置目录。Claude Code、WorkBuddy、opencode 与 ZCode 会对账各自的 Hook/插件，Codex 与 TRAE 分别检查 rollout 和日志只读监听器。最近事件时间只来自内存中的会话元数据，不读取或展示提示词、回复正文、项目完整路径或运行时令牌。

设置窗口中的开机启动和隐私开关会立即生效；下班彩蛋时间保存到本机配置，只在 Codex 喵伴空闲或休息时播放，任务进行中会自动让位。Agent 接入区域可卸载 WorkMeow 管理的 Hook 和插件，不会卸载 Agent 本体，之后仍可一键修复。

隐私模式开启后，项目名、消息正文、授权命令、方案/问题选项和操作流明细会立即遮蔽，但工作状态和用量仍保留。关闭隐私模式后，未处理的授权或回复会重新出现。

## 常用命令

```powershell
npm run start:console
npm test
npm run install:hooks
npm run uninstall:hooks
npm run meter:rebuild
```

`npm test` 覆盖本地 server、权限生命周期、状态聚合、隐私遮蔽、价格解析与同步、Codex App Server 额度协议、六个 Agent 接入、设置配置、休息提醒、免打扰、拖动坐标和边缘菜单几何。网络价格同步失败不会让测试连接被异常重置；程序会保留有效缓存、反馈失败状态并自动重试。

## 数据边界

所有会话和统计数据保存在本机的 `~/.workmeow/`。价格同步只下载公开价目表，不上传 transcript、rollout 或权限内容。Codex 额度请求通过官方 App Server 发出，WorkMeow 仅持久化不含凭据的提醒去重键。服务只监听本机回环地址，写请求需要运行时令牌。

更完整的文件结构和维护约定见根目录的 [README](../README.md) 和 [状态规范](../STATES.md)。

## 设计参考

- 休息提醒参考 [Codex Pet Pause 的提醒调度设计](https://github.com/ccofallen/codex-pet-pause/blob/main/src/features/reminders/domain/scheduler.ts)，借鉴稍后提醒、今日跳过与避免连续催促的交互。本项目根据电脑使用时间独立实现调度，提醒不依赖 AI 任务结束，喵与胶囊共用一套状态。
- 全屏免打扰参考 [Codex-Desktop-PET 的全屏监听设计](https://github.com/moujunjie/Codex-Desktop-PET/blob/main/electron/fullscreen-watcher.js)，借鉴后台检测前台窗口覆盖显示器、进入时隐藏与退出时恢复的机制。本项目独立实现 Windows 检测，并结合现有收起入口、临时安静和手动显示状态控制恢复行为。
